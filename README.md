# Симулятор жизни с душой

Веб-игра: проживи одну жизнь по реальной статистике мира или эпохи, поделись карточкой жизни, а душа запомнит прожитое.

- Играть: https://rusaved.github.io/life-sim/ (сборка для VK и ОК — `vk/`)
- Дизайн — `docs/01-design.md`, вехи — `docs/05-milestones.md`, источники данных — `docs/data-sources.md`
- Запуск: `npm ci`, `npm run dev`; проверки — `npm run verify:fast`, перед выкладкой — `npm run verify`

Данные: World Bank Open Data (CC BY 4.0); для эпох России — Росстат, Human Mortality Database, Демоскоп, переписи населения. Тексты, события и вид — свои.
