# Источники данных

## Режим «Мир» — `content/data/world.json`
- World Bank Open Data, World Development Indicators, лицензия CC BY 4.0 — https://data.worldbank.org
- Показатели: рождаемость на 1 000 (SP.DYN.CBRT.IN), население (SP.POP.TOTL), ожидаемая продолжительность жизни (SP.DYN.LE00.IN), младенческая смертность (SP.DYN.IMRT.IN), смертность до 5 лет (SH.DYN.MORT), городское население (SP.URB.TOTL.IN.ZS), грамотность взрослых (SE.ADT.LITR.ZS), ВВП на душу по ППС (NY.GDP.PCAP.PP.CD); группа дохода страны — из справочника стран Всемирного банка
- Год: последний доступный по каждому показателю (2024–2025, грамотность — 2022–2024), выгрузка 28.10.2026
- Доля рождений страны = рождаемость × население / 1 000; 50 стран — 86 % рождений мира, остальные — по регионам (`otherByRegion`, средние, взвешенные по рождениям)
- Названия стран на русском — через `Intl.DisplayNames('ru', { type: 'region' })` по коду `iso2`

## Режим «Россия и эпохи» — `content/data/russia-eras.json`
- Исторические оценки по территории России для эпох 1900–2020: ожидаемая продолжительность жизни (все, мужчины, женщины), младенческая смертность на 1 000, доля городского населения, доля столиц, грамотность, рождений в год
- Источники у каждой эпохи — в поле `sources` (Росстат, Human Mortality Database, Демоскоп, переписи); сверено вторым проходом 28.10.2026, спорные цифры помечены в `notes`
- Для ранних эпох (1900–1940) цифры — оценки демографов, в игре подаются как «приблизительно»

## Как данные попадают в игру
- Рождение в «Мире»: страна выпадает с вероятностью, равной её доле рождений (`birthShare`); 50 стран — 86,4 % рождений, остальные 13,6 % — «Другая страна: <регион>» со средними по регионам Всемирного банка
- Рождение в «России и эпохах»: эпоха — по числу рождений в год (`birthsPerYear`), место — по долям столиц и городского населения эпохи; год рождения — внутри десятилетия
- Длина жизни: риск смерти по годам подобран так, чтобы ожидаемая длина жизни совпала с данными места (младенческая смертность, смертность до 5 лет, старение по закону Гомперца — Мейкхема); для эпох России добавлены годы войн и голода (оценки, внутри той же ожидаемой длины жизни); у «Мира» разница женщин и мужчин — ±2,5 года от общей цифры (оценка ООН, около 5 лет)
- Сверка: бот проживает 200 жизней в каждом режиме и сравнивает средний возраст смерти с данными — `npm run sim:lives`, отчёт `docs/evidence/LS1/sim-lives.md`
- Названия стран на русском — `content/data/country-names.json` (по `Intl.DisplayNames`, короткие формы вручную: США, ЮАР, ДР Конго, Мьянма)
- На экране «Об игре» — источники и годы данных; в сборке `vk/` адреса источников убраны из данных (правило площадки: никаких чужих адресов), названия источников остаются
