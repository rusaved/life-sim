# Источники данных

## Режим «Мир» — `content/data/world.json`
- World Bank Open Data, World Development Indicators, лицензия CC BY 4.0 — https://data.worldbank.org
- Показатели: рождаемость на 1 000 (SP.DYN.CBRT.IN), население (SP.POP.TOTL), ожидаемая продолжительность жизни (SP.DYN.LE00.IN), младенческая смертность (SP.DYN.IMRT.IN), смертность до 5 лет (SH.DYN.MORT), городское население (SP.URB.TOTL.IN.ZS), грамотность взрослых (SE.ADT.LITR.ZS), ВВП на душу по ППС (NY.GDP.PCAP.PP.CD); группа дохода страны — из справочника стран Всемирного банка
- Год: последний доступный по каждому показателю (2024–2025, грамотность — 2022–2024), выгрузка 28.10.2026
- Доля рождений страны = рождаемость × население / 1 000; 50 стран — 86 % рождений мира, остальные — по регионам (`otherByRegion`, средние, взвешенные по рождениям)
- Названия стран на русском — через `Intl.DisplayNames('ru', { type: 'region' })` по коду `iso2`
